# GLAMAI – AI-Powered Peacock Jewelry E-Commerce Platform

GLAMAI is a modern full-stack e-commerce web application built for showcasing handcrafted peacock-themed jewelry. The application features a responsive React frontend, a Node.js/Express backend, and a clean user interface for browsing products.

---

## Features

- Responsive and modern UI
- Product catalog with categories
- Product detail pages
- Search and filtering
- Shopping cart interface
- REST API integration
- Client-Server Architecture
- Mobile-friendly design
- Fast loading with Vite

## Installation

Clone the repository

```bash
git clone https://github.com/yourusername/glamai-fullstack.git
```

Move into the project

```bash
cd glamai-fullstack
```

Install dependencies

```bash
npm install
```

Install client dependencies

```bash
cd client
npm install
```

Install server dependencies

```bash
cd ../server
npm install
```

Return to root directory

```bash
cd ..
```

---

## Running the Project

Start both frontend and backend

```bash
npm run dev
```

Or run individually

Backend

```bash
cd server
npm start
```

Frontend

```bash
cd client
npm run dev
```
